# Writing Styles and Article Structure

## Four styles

| Style | Structure | Best fit |
|---|---|---|
| Deep analysis | Problem → Analysis → Conclusion | Clear thesis, rigorous argument, strong evidence |
| Narrative story | Situation → Conflict → Insight | Real experience, story arc, insight through experience |
| Practical guide | Problem → Method → Steps → Result | Clear steps, hands-on, actionable |
| Opinion / commentary | Viewpoint → Evidence → Rebuttal → Conclusion | Strong stance, unique angle, provokes thought |

Recommend one style per article and let the user confirm before composing.

## Article structure

- Title: 2–3 candidates, each with a different angle (question, conclusion, value).
- Intro: hook sentence + background + value promise (the core question, what the reader gains).
- Body: one core point per section, each with examples or analysis and a subheading.
- Conclusion: distill the insight, then give a direction or an open thought.
- Transitions: natural logical links between sections, no abrupt jumps.
