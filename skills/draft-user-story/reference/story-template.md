# User Story Template

Used by **draft-user-story** (step 1); the drafting examples render the same shape.

```markdown
## User Story

**As a** [user role],
**I want** [functionality],
**So that** [benefit].

---

### Acceptance Criteria

**Scenario 1: [Happy Path Title]**
- **Given** [precondition]
- **When** [action]
- **Then** [expected outcome]

**Scenario 2: [Error/Edge Case Title]**
- **Given** [precondition]
- **When** [action]
- **Then** [expected outcome]

---

### Out of Scope
- [Item 1]: [brief reason]
- [Item 2]: [brief reason]

---

### Prerequisites
- [Prerequisite 1]
- [Prerequisite 2]
```
