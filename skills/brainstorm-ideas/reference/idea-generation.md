# Idea Generation

Used by **generate-ideas** to produce a diverse candidate set.

## Count
Generate **5–7 diverse ideas** per round. Use fewer when the topic is narrow; use more only when the user asks.

## Thinking techniques
Apply one technique per pass to force different angles:

| Technique | How | Example |
|---|---|---|
| Analogy | Borrow from a different domain | "Like a gym streak, but for reading" |
| Inversion | Flip the problem or a constraint | "How could users read less? Reverse it" |
| Combination | Merge two unrelated ideas | "Book club + habit tracker" |
| Elimination | Remove a core element and rebuild | "No manual logging at all" |

## Perspectives
Cover these across the set:
- **Audience need** — who benefits and how
- **Technical possibility** — can it be done with available means
- **Value** — how well it serves the goal
- **Landscape** — what exists and what is missing

## Range and framing
- Include incremental improvements and bold innovations
- Frame ideas as outcomes and value, not just features

## Present as a mind map
Show relationships as a tree; keep depth to 2–3 levels; use descriptive labels, not keywords.

```
Central Theme
├── Branch 1
│   ├── Sub-idea 1a
│   └── Sub-idea 1b
├── Branch 2
└── Branch 3
```
