# Idea Evaluation

Used by **evaluate-ideas** to score and prioritize.

## Dimensions
Score each idea low / medium / high on every dimension:

| Dimension | Question to ask |
|---|---|
| Value | How well does it serve the goal or solve the problem? |
| Feasibility | Can it be done with available time and resources? |
| Differentiation | What makes it unique or better than alternatives? |
| Scope | Is it right-sized for the situation? |
| Impact | What is the potential reach and effect? |

## Critique rules
- Give honest, constructive critique
- State risks, challenges, and trade-offs per idea
- Suggest improvements or variations

## Prioritization frameworks
- **Effort vs impact**: plot on a 2×2; do high-impact, low-effort first
- **MoSCoW**: label each idea Must / Should / Could / Won't for this round
