# Plan Output Format

Used by **compile-actionable-plan** to structure the final plan.

```markdown
## Refined Idea
[One-paragraph summary of the refined idea]

## Goals
- [Goal 1]

## Challenges & Solutions
| Challenge | Solution |
|---|---|
| [Challenge] | [Solution] |

## Key Components
- [Component 1]

## Next Steps
- [Actionable step 1]
```
